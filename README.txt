Free static website package for GitHub Pages

FILES
- index.html: website content and structure
- styles.css: responsive styling
- script.js: collection filters, enquiry cart, and WhatsApp enquiry forms
- assets/: place your real product photos here when ready

PREVIEW ON YOUR COMPUTER
1. Extract the ZIP file.
2. Open the natraj_website folder.
3. Double-click index.html to preview the website in your browser.

PUBLISH FREE USING GITHUB PAGES
1. Sign in or create a free account at https://github.com/.
2. Click + (top-right) > New repository.
3. Give the repository a name such as natraj-brand-website and choose Public.
4. Create the repository.
5. Click Add file > Upload files.
6. Open the extracted natraj_website folder on your computer and upload index.html, styles.css, script.js, README.txt, and the assets folder (if it contains files). Upload the FILES INSIDE the folder, not the outer folder itself. Keep index.html at the repository root.
7. Commit the upload.
8. Open the repository's Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch. Select branch main and folder /(root), then Save.
10. Wait a few minutes and revisit Settings > Pages to see the published URL. A project site usually looks like https://YOUR-USERNAME.github.io/natraj-brand-website/.

- GitHub Pages provides free static hosting and a github.io web address. It does not give you a free custom .com domain.
